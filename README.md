## ✨ 核心功能

### 1. 网课进度助手（全自动生效）
针对机构/平台网课学习页面设计，**无需任何手动配置，打开网页自动识别激活**：
- **彩色学习状态标签**：自动扫描目录中的百分比进度，为每一节课添加高对比度彩色胶囊徽章：
  - `✅ 已看完`（100% 学习完成，背景柔和变灰，减少视觉干扰）
  - `⏳ xx% 学习中`（进行中课时，橙黄色高亮聚焦）
  - `⚪ 未学习`（0% 待学课时，灰色简洁标注）
- **现代化毛玻璃悬浮控制条**：常驻网页右下角，支持最小化/展开，提供快捷操作：
  - **📍 定位进度**：一键平滑滚动到当前正在学习（或上一次观看）的课程行，并伴随脉冲高亮动画。
  - **📂 展开期数**：自动遍历并展开包含您未完成进度的所属期数（如第二期、第三期等折叠面板）。
  - **🔍 仅未学完**：一键隐藏所有已 100% 看完的视频，专注剩余课程目录。
- **本地记忆与单课点击跟踪**：点击任意课程自动记录为当前学习焦点，下次打开网页即可无缝续学。

### 2. 智能域名识别与站点管理
在选项设置页（`options.html`）中彻底告别繁琐的手动编辑：
- **任意网址自动清洗**：直接复制浏览器地址栏的完整长链接（无论带不带 `https://`、参数或长路径），直接粘贴进输入框，系统**毫秒级自动识别并提取出纯域名**（例如 `ke.qq.com`）。
- **一键读取已打开标签页**：自动扫描您当前浏览器正在浏览的全部网页，以卡片形式展示，**点击卡片上的「+添加」即可秒级入库**，无需复制粘贴。
- **规则导入与导出**：支持将常用站点配置导出为 JSON 备份，并在多设备间一键恢复。

### 3. 新标签页智能打开
- 灵活配置指定域名或临时控制链接点击是在当前页还是新标签页中打开。
- 支持后台静默打开、页面滚动时动态绑定新渲染链接、属性监听等高级选项。

## 🚀 怎么安装到 Chrome / Edge

1. **打开浏览器的扩展管理页**：
   - 在 Chrome 地址栏输入：`chrome://extensions/`
   - *(若是 Edge 浏览器输入：`edge://extensions/`)*
2. **开启「开发者模式」**：
   - 查看页面**右上角**，将 **「开发者模式」 (Developer mode)** 开关切换为**打开**。
3. **加载插件**：
   - 点击页面左上角出现的 **「加载已解压的扩展程序」 (Load unpacked)** 按钮。
   - 在弹出的文件选择器中，选中本项目的**根目录**：
     ```text
     e:\Web\TabFlow
     ```
     > ⚠️ **注意**：选择包含 `manifest.json` 的外层根文件夹 `TabFlow`，不要选进 `js` 或 `css` 等子文件夹。
4. **钉选图标（可选）**：
   - 点击浏览器右上角拼图图标 🧩，找到 **TabFlow** 并点击图钉 📌 固定到浏览器工具栏。

## 📖 功能使用指南

### 如何使用网课助手
1. 安装好插件后，直接在浏览器中打开您的**网课视频目录页面**。
2. 页面加载完成后：
   - 目录右侧会自动呈现彩色进度胶囊。
   - 页面右下角会自动出现 **【🎓 网课助手】** 悬浮控制面板。
3. **常用操作**：
   - 点击 **📍 定位进度**：瞬间跳转到正在看的视频，不用手动翻页找进度。
   - 点击 **📂 展开期数**：自动展开你正在学的那一期。
   - 点击 **🔍 仅未学完**：瞬间清爽，已学课程全隐去。

### 如何添加与管理网站
1. 右键点击浏览器右上角 TabFlow 图标，选择 **「选项」** 进入管理页。
2. **两种超便捷添加方式**：
   - **方式一（一键直加）**：看输入框下方的“检测到已打开的标签页”，直接点击想要添加的网站名称后的 **`+添加`**。
   - **方式二（直接粘贴）**：直接把网页地址栏整串网址 `Ctrl + V` 粘贴到输入框，它会自动识别纯域名，点击 **添加** 即可。

## 🛠️ 修改代码后如何更新生效

如果您修改了扩展的代码（如调整了 CSS 样式或 JS 逻辑）：
1. 回到浏览器的扩展管理页：`chrome://extensions/`
2. 找到 **TabFlow** 卡片。
3. 点击卡片右下角的 **刷新图标（↻）**。
4. 切换到对应的网页，按键盘 **`F5`（或 `Ctrl + F5`）** 刷新网页即可看到最新改动。

## ❓ 常见问题与排错 (FAQ)

#### Q1：网课页面打开后没有出现控制条或彩色标签？
1. 请检查该网页是否包含学习进度百分比（如 `0%`、`100%`）或课程目录结构。
2. 尝试按 `F5` 刷新一次网页。
3. 按 `F12` 打开浏览器开发者工具，在 **Console (控制台)** 查看是否有 `[TabFlow] 🎓 Course page detected.` 的输出信息。

#### Q2：粘贴网址后域名识别报错？
本插件已内置智能 URL 解析器，无论粘贴带有协议的完整路径还是纯域名均可自动识别。如果提示无效，请确认粘贴的内容是否包含有效的网站后缀（如 `.com`、`.cn`、`.net` 等）。
