# TabFlow

TabFlow 是一款现代化的浏览器扩展（Manifest V3），用于灵活控制链接在新标签页中打开的行为，并支持针对特定网课/网页的学习进度增强与导航。

## 主要特性

- **在新标签页打开链接**：可一键为当前域名开启在新标签页打开链接，或在当前页面临时启用。
- **丰富的定制选项**：
  - 在后台打开链接
  - 滚动或属性变化时动态更新链接
  - 自动重新加载与上下文菜单集成
- **网课学习增强（计划中）**：
  - 自动识别并醒目标注各章节学习进度（已看/进行中/未看）
  - 课程多期导航优化与自动展开、定位到上次播放集数

## 安装使用

1. 打开 Chrome / Edge 浏览器，访问扩展管理页面（`chrome://extensions/` 或 `edge://extensions/`）。
2. 开启右上角 **「开发者模式」**。
3. 点击 **「加载已解压的扩展程序」**（Load unpacked）。
4. 选择本项目根目录即可。
